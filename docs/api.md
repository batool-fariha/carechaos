# HTTP API

All endpoints return JSON. Experiment IDs look like `exp_…`. The API is meant for the bundled UI, but it is stable enough to script against.

| Method and path | Purpose | Notes |
|---|---|---|
| `GET /api/health` | Liveness and storage status | `503` if storage is unavailable |
| `GET /api/experiments` | List **your** experiments | Scoped by the anonymous `cc_owner` cookie |
| `POST /api/experiments` | Create | Body `{ "config": ExperimentConfig, "status": "created" \| "completed" \| "stopped" }`. Sets the owner cookie. `422` with `issues[]` if the config is invalid |
| `GET /api/experiments/:id` | Read one | Public to anyone with the ID (this is how share links work) |
| `PUT /api/experiments/:id` | Update | Owner only (`403` otherwise) |
| `DELETE /api/experiments/:id` | Delete | Owner only (`404` otherwise) |
| `DELETE /api/experiments` | Delete all of **your** experiments | Scoped by cookie |
| `GET /api/experiments/:id/report?format=json\|md` | Download a report | Regenerated by replaying the stored config. `409` if never run |

**Auth (only when GitHub sign-in is configured; otherwise these return `404`):**

| Method and path | Purpose |
|---|---|
| `GET /api/auth/me` | `{ enabled, user: { login } \| null }`. Never returns tokens or IDs |
| `GET /api/auth/github` | Starts sign-in (redirects to GitHub) |
| `GET /api/auth/github/callback` | OAuth callback; verifies `state`, sets the session, claims anonymous history |
| `POST /api/auth/logout` | Clears the session cookie |

**Verdict and summary are always computed server-side** by replaying the engine from the stored configuration; clients cannot set them.

**Rate limiting:** write requests are limited to 30 per minute per client IP (best effort). Excess requests get `429` with a `Retry-After` header.

`ExperimentConfig` is documented in [report-schema.md](report-schema.md) (the `configuration` field) and validated by `src/engine/config.ts`.
