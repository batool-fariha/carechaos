# Security policy

CareChaos is a simulation tool and handles no real patient data. If you find a vulnerability (for example in the API, the ownership model or the rate limiter), please report it privately through [GitHub private vulnerability reporting](https://github.com/batool-fariha/carechaos/security/advisories/new) rather than a public issue. Include steps to reproduce and the impact you see. You can expect an acknowledgement within a few days.

The security model is described in [docs/security.md](docs/security.md).
